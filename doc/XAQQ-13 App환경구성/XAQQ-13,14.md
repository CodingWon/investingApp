  - backend/ - FastAPI 백엔드

  2. 백엔드 (FastAPI)

  - backend/requirements.txt - Python 의존성
  - backend/main.py - FastAPI 기본 설정 (CORS 포함)
  - backend/.env.example - 환경 변수 템플릿

  3. 프론트엔드 (React + TypeScript + MUI)

  - React 앱 생성 (TypeScript 템플릿)

  - frontend/.env.example - 환경 변수 템플릿

  4. 데이터베이스

  - docker-compose.yml - MongoDB + Mongo Express 설정
    - MongoDB: localhost:27017
    - Mongo Express: localhost:8081 (admin/admin)

  5. 기타

  - .gitignore - 필요한 파일 제외 설정
  - README.md - 프로젝트 문서 및 실행 가이드

  다음 단계

  1. MongoDB 시작: docker-compose up -d
  2. 백엔드 실행:
  cd backend
  python -m venv venv
  source venv/bin/activate
  pip install -r requirements.txt
  cp .env.example .env
  uvicorn main:app --reload
  3. 프론트엔드 실행:
  cd frontend
  cp .env.example .env
  npm start
